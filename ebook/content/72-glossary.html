Glossary

Affiliate commission
A share of a sale paid to you for referring a customer to another seller’s product.
Agent (AI agent)
A program that pursues a goal by deciding on steps and using tools, without a person directing every action.
Agent-native system
A business that packages a method as a plugin for a customer’s AI assistant, usually with a dashboard for oversight (Model 4).
Aggregation
Combining individual records into group statistics such as averages.
AGPL (AGPLv3)
A strong copyleft license requiring anyone who runs a modified version as a network service to share their changes.
Ambient agent
An AI that lives in the background of everyday tools, such as group chats, and acts when needed (Model 6).
Anonymization
Removing details that could identify a person from data.
API
Application programming interface: a defined way for software to request data or actions from other software.
Bot API
A messaging platform’s official interface for automated accounts.
Churn
The share of customers who cancel in a given period.
CLI
Command-line interface: a program operated by typed commands in a terminal.
Cold start
The early stage when a data or network product has too little data or too few users to be useful.
Connector
A link that lets an AI agent use another application.
Contributor license agreement (CLA)
An agreement giving an open-source project the rights it needs to outside contributions.
Copyleft
A licensing approach that requires derivative works to be shared under the same terms.
Core action
The single thing a product does better than anything else.
Credits
Prepaid units customers spend down as they use a service.
Data flywheel
A loop in which use generates data, data improves the product, and a better product attracts more use.
Deliverable
The specific output a client receives.
Dual licensing
Offering the same code under an open-source license and, for a fee, a commercial license.
Evaluation set (evals)
A collection of real test cases with known-good answers used to measure output quality.
Fair source / source-available
Licenses that make code visible and usable but restrict competing commercial services.
Give-to-get
A collection strategy where users contribute their data to unlock everyone else’s.
Gross margin
Revenue minus the direct cost of delivering the product, as a percentage of revenue.
Harness
The tools, knowledge, rules, memory, and workflows built around an AI model for one job (Model 2).
Headless software
Software without a graphical interface, used by other programs and agents (Model 3).
Horizontal product
A product built for many industries or everyone.
Hosted cloud
A vendor-run version of software that customers pay to use without managing servers.
Human-in-the-loop review
A checkpoint where a qualified person reviews AI output before it’s used.
JSON
A lightweight, structured text format for data.
Lead magnet
Something valuable given free in exchange for contact details.
llms.txt
A plain-text file summarizing a product’s documentation for AI agents.
MCP (Model Context Protocol)
An open standard that lets compatible AI agents discover and use external tools and data.
Moat
A durable advantage that makes a business hard to copy.
Open core
A free open-source core product with paid features for businesses.
Open source
Software whose code is public under a license permitting use, modification, and sharing.
Per-outcome pricing
Charging for a measurable result rather than for time or access.
Platform risk
Dependence on a platform whose rules, fees, or features you don’t control.
Playbook
A reusable set of instructions and examples that tells an AI how to perform a step your way.
Plugin
An installable package that adds skills, commands, sub-agents, or connectors to an AI assistant.
Positioning map
This book’s two-axis chart placing the eight models by who does the work and what is sold.
Productized service
A service sold with a fixed scope, price, and turnaround, like a product.
Proprietary data
Data only you possess, gathered through your own product or relationships (Model 7).
Re-identification
Working out a person’s identity from supposedly anonymous data.
Retainer
A recurring fee for an agreed scope of ongoing work.
Retention
The share of users or groups still active after a period of time.
Retrieval
Searching a knowledge base and giving the most relevant material to an AI model as context.
Revenue per person
Total revenue divided by team size; a key efficiency measure.
Roll-up
Buying several traditional firms and combining or transforming them.
Self-hosting
Running software on your own servers.
Skill
Written instructions, templates, and examples that teach an AI to do a task a particular way.
SLA
Service-level agreement: a contractual promise about uptime or response times.
Software-enabled service
A firm that sells finished work produced with AI systems and a small team (Model 1).
Sub-agent
A specialized AI assistant the main agent can delegate a narrow task to.
Taste
An insider’s sense of what matters and what’s missing in a community’s world (Model 5).
Thin wrapper
A product that adds little beyond a prompt and an interface on top of a general model.
True fan
A customer who will use, pay for, and promote what you make.
Usage-based pricing
Charging per unit consumed, such as per call, page, or search.
Validation
Testing demand with real potential customers before building.
Vertical product
A product built deeply for one industry or user type.
Weekly active groups
The number of groups that used a group product in a given week.
